    ─────────────────────────────────────────────────────────────────────────────────
                             记忆类型说明
    ─────────────────────────────────────────────────────────────────────────────────

    ┌──────────────────────────────────────────────────────────────────────────────┐
    │  工作记忆 (Working Memory) - 短期记忆                                  │
    │    • 存储当前对话上下文                                                     │
    │    • 容量: 5轮对话                                                          │
    │    • 实时更新                                                               │
    └──────────────────────────────────────────────────────────────────────────────┘

    ┌──────────────────────────────────────────────────────────────────────────────┐
    │  情景记忆 (Episodic Memory) - 中期记忆                                 │
    │    • 记录查询历史                                                           │
    │    • 记录训练事件                                                           │
    │    • 记录学习事件                                                           │
    └──────────────────────────────────────────────────────────────────────────────┘

    ┌──────────────────────────────────────────────────────────────────────────────┐
    │  语义记忆 (Semantic Memory) - 长期记忆                                  │
    │    • profile: 目标、水平、年龄                                              │
    │    • preference: 训练偏好、时间偏好                                         │
    │    • habit: 训练习惯、行为模式                                              │
    │    • constraint: 伤病、限制条件                                             │
    │    • risk: 风险因素                                                         │
    └──────────────────────────────────────────────────────────────────────────────┘

    ┌──────────────────────────────────────────────────────────────────────────────┐
    │  感知记忆 (Perceptual Memory) - 感知特征                               │
    │    • 存储文档特征                                                           │
    │    • 存储图像描述                                                           │
    │    • 多模态信息管理                                                         │
    └──────────────────────────────────────────────────────────────────────────────┘

    ┌──────────────────────────────────────────────────────────────────────────────┐
    │  训练规律分析                                                        │
    │    • 训练频率趋势                                                           │
    │    • 训练类型偏好                                                           │
    │    • 疲劳/疼痛模式                                                          │
    │    • 完成率统计                                                             │
    │    • 风险因素识别                                                           │
    └──────────────────────────────────────────────────────────────────────────────┘
